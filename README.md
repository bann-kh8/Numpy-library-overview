# NumPy Fundamentals 🧮

## 📌 About the Project
This project covers the fundamentals of NumPy in Python through practical examples and exercises. It demonstrates how to create, manipulate, and analyze arrays efficiently using the NumPy library.

## 🎯 Topics Covered

### 1. Introduction to NumPy
- Importing NumPy and checking its version.
- Creating arrays from lists and existing data.
- Generating arrays using comprehensions.

### 2. Array Attributes
- `dtype`: Data type of array elements.
- `ndim`: Number of dimensions.
- `shape`: Dimensions of the array.
- `size`: Total number of elements.
- `itemsize`: Memory size of each element.
- `flat`: Iterating over array elements.

### 3. Array Creation
- Creating arrays using `zeros()`, `ones()`, `full()`, `eye()`, and `empty()`.
- Generating sequences using `arange()` and `linspace()`.
- Creating random arrays using `rand()`, `randint()`, and `randn()`.

### 4. Array Operations
- Arithmetic operations between arrays and numbers.
- Broadcasting.
- Comparing arrays and filtering elements using Boolean masks.
- Using augmented assignment operators.

### 5. NumPy Calculation Methods
- `sum()`, `min()`, `max()`, `mean()`, `std()`, and `var()`.
- Performing calculations along rows and columns using `axis`.

### 6. Universal Functions
- Mathematical functions such as `sqrt()`, `add()`, `multiply()`, and `power()`.

### 7. Indexing and Slicing
- Accessing individual elements, rows, and columns.
- Selecting multiple rows or columns.
- Filtering array elements using conditions.

### 8. Copying Arrays
- Understanding references and views.
- Shallow copying and deep copying.
- Using `copy()` and `np.copy()`.

### 9. Reshaping and Transposing
- `reshape()` and `resize()`.
- `flatten()` and `ravel()`.
- Transposing arrays using `.T`.
- Combining arrays using `hstack()` and `vstack()`.

### 10. Practical Exercises
- Converting array data types.
- Applying Boolean conditions to select and modify data.
- Working with multidimensional arrays.

## 🛠️ Technologies Used
- Python
- NumPy
- Google Colab

## 📚 Learning Goal
The goal of this project is to build a strong foundation in NumPy for numerical computing, data manipulation, and future Data Science and Machine Learning projects.
